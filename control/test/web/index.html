Tello 제어 테스트

서버: uv run python -m api 후 브라우저에서 이 페이지를 열면 됩니다 (예: http://서버IP:8000/test-web/). 서버 주소 칸은 비우거나 그대로 두면 지금 접속한 호스트·포트로 API를 호출합니다. 다른 주소의 API를 쓸 때만 수정하세요. 아래 암호는 modules/ctrl.py의 API_AUTHORIZATION 과 같아야 합니다.

드론 연결은 서버가 시작될 때 DB 기반으로 자동 수행됩니다(클라이언트 연결 버튼 없음). 이륙이 실패하면 배터리(너무 낮으면 불가)·평평한 바닥·주변 여유를 확인하고, 진단 정보 또는 아래 배터리를 보세요. 이륙 (스트림 잠시 끄고)도 시험해 볼 수 있습니다. 착륙은 공중에 있을 때만 됩니다.

주소·암호

예: main, remote-1008 (remote-1008은 스트리밍 전용)

미션 시작

`/missions/start` 호출. 내부 action 요청/응답 trace는 응답 JSON의 `trace`로 확인.

배터리
배터리: — %
드론에 연결한 뒤 자동으로 갱신됩니다.

체크 후 키 입력 시 색이 바뀌며 조작 명령이 전송됩니다.

W/S: 상하, A/D: 회전, 방향키: 전후좌우
W (상)
A (좌회전)
●
D (우회전)
S (하)
↑ (전진)
← (좌)
●
→ (우)
↓ (후진)
현재 전송값: lr=0 fb=0 ud=0 yaw=0
