================================================================================
control — 빠른 안내 (API 실행·테스트)
================================================================================

모든 명령은 저장소에서 **`control` 디렉터리로 이동한 뒤** 실행한다.
(`api`, `modules` 패키지 경로가 맞아야 한다.)

--------------------------------------------------------------------------------
0. 환경 구축
--------------------------------------------------------------------------------

의존성 전체 목록·역할별 설치 방법:

    ../DEPENDENCIES.md
    requirements-report.txt   (보고서 LLM 전용)

권장 (제어 API):

    cd control
    uv sync

Linux 추가 패키지:

    sudo apt install -y libgl1 libglib2.0-0

--------------------------------------------------------------------------------
1. API 서버 실행
--------------------------------------------------------------------------------

방법 A — 모듈 실행 (기본 호스트 0.0.0.0, 포트 8000)

    cd control
    uv run python -m api

방법 B — uvicorn 직접 지정 (호스트·포트 바꿀 때)

    cd control
    uv run uvicorn api.main:app --host 0.0.0.0 --port 8000

실행 후 확인:

    curl -s http://127.0.0.1:8000/health

브라우저에서 OpenAPI 문서: http://127.0.0.1:8000/docs

인증이 필요한 API를 호출할 때는 HTTP 헤더 `Authorization` 값을
`modules/ctrl.py` 의 `API_AUTHORIZATION` 과 동일하게 맞춘다.


--------------------------------------------------------------------------------
2. API 테스트
--------------------------------------------------------------------------------

(1) 웹 UI (권장 — 서버만 띄우고 브라우저만 있으면 됨)

    브라우저에서 http://127.0.0.1:8000/test-web/
    (다른 머신이면 http://서버IP:8000/test-web/ )

    같은 호스트로 열면「서버 주소」는 자동으로 맞춰진다. Authorization 만
    `ctrl.py` 의 `API_AUTHORIZATION` 과 같게 두고 버튼으로 JSON-RPC 호출.
    영상은 snapshot 폴링으로 미리보기.

    test/test_api.py 는 실행할 필요 없음.


(2) 자동 스모크 스크립트 (선택, CI·회귀용)

    cd control
    uv run python test/test_api.py

다른 포트·호스트를 쓰는 경우:

    uv run python test/test_api.py --base http://127.0.0.1:8000

내용: 인증 없이 401, 인증 후 ping, snapshot(스트림 없으면 503 등) 확인.


(3) 수동 curl 예 (암호는 환경에 맞게)

    export AUTH='tello-api-secret-change-me'

    curl -s -X POST http://127.0.0.1:8000/rpc \
      -H "Content-Type: application/json" \
      -H "Authorization: $AUTH" \
      -d '{"jsonrpc":"2.0","method":"ping","id":1}'


(4) 드론 Wi-Fi에 PC를 붙인 뒤 로컬에서 카메라만 확인 (API 아님, test/web 과 무관)

    cd control
    uv run python test/stream_view.py

4. 이륙(takeoff)이 error 로 실패할 때
--------------------------------------------------------------------------------

Tello가 텍스트 응답 `error` 를 돌려주면, 기체가 명령을 거절한 것이다(영상 스트림과
무관할 수도 있고, 배터리·자세·환경 때문일 수도 있다).

가능한 점검:

  - 배터리: 약 20% 미만이면 이륙이 거절되는 경우가 많다. JSON-RPC `diagnostics`
    또는 `battery` 로 확인한다.
  - 바닥·자세: 평평한 바닥에 두고, 프롭·장애물이 가까우면 실패할 수 있다.
  - 공식 Tello 앱으로 이륙이 되는지 확인해 하드웨어·펌웨어 문제를 배제한다.
  - UDP 부하 완화: 스트림이 켜진 상태에서만 실패할 때, `takeoff` 에
    `params: {"pause_stream_first": true}` 를 주어 스트림을 잠시 끄고 이륙 후
    다시 켜는 시도를 할 수 있다. 테스트 웹 페이지의 **takeoff (스트림 끄고)** 버튼과 동일.

착륙(land)이 `error` 인 경우: 이미 공중에 있지 않으면(이륙에 실패한 직후 등)
Tello가 `error` 를 반환하는 것이 일반적이다.
