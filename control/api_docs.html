Tello HTTP API 문서

control 디렉터리에서 서버를 실행한 뒤 아래 URL을 사용한다.

  • 기본 베이스 URL: http://127.0.0.1:8000 (포트는 실행 시 바뀔 수 있음)
  • 인증: HTTP 헤더 Authorization 값이 modules/ctrl.py의 API_AUTHORIZATION 상수와 완전히 동일해야 한다. (아래 예시에서는 기본값 tello-api-secret-change-me 사용)

쉘에서 반복 사용할 때:

export BASE='http://127.0.0.1:8000'
export AUTH='tello-api-secret-change-me'

공통

항목 설명
인증 필요 POST /rpc, GET /snapshot.jpg, GET /stream.mjpeg
인증 불필요 GET /, GET /health, GET /docs, GET /test-web/

GET /

API 안내 JSON.

curl 예시

curl -s "${BASE:-http://127.0.0.1:8000}/"

GET /health

서버 생존 확인.

응답 예: {"status":"ok"}

curl 예시

curl -s "${BASE:-http://127.0.0.1:8000}/health"

GET /docs

Swagger UI (OpenAPI). 브라우저에서 연다.

curl 예시 (HTML이 반환됨)

curl -s -o /dev/null -w "%{http_code}\n" "${BASE:-http://127.0.0.1:8000}/docs"

GET /test-web/

로컬 테스트용 정적 웹 페이지 (control/test/web/). 인증 없이 HTML만 제공한다.

curl 예시

curl -s -o /dev/null -w "%{http_code}\n" "${BASE:-http://127.0.0.1:8000}/test-web/"

브라우저:

http://127.0.0.1:8000/test-web/

POST /rpc

JSON-RPC 2.0 단일 요청 객체를 본문에 넣는다.

필수 헤더

  • Content-Type: application/json
  • Authorization: <API_AUTHORIZATION과 동일>

요청 본문 형식

{
  "jsonrpc": "2.0",
  "method": "<메서드명>",
  "params": { },
  "id": 1
}
  • params는 생략 가능(내부에서 빈 객체로 처리).
  • method는 drone.connect처럼 drone. 접두어를 붙여도 동일하게 처리된다.

curl 예시 — ping

curl -s -X POST "${BASE:-http://127.0.0.1:8000}/rpc" \
  -H "Content-Type: application/json" \
  -H "Authorization: ${AUTH:-tello-api-secret-change-me}" \
  -d '{"jsonrpc":"2.0","method":"ping","id":1}'

curl 예시 — connect

curl -s -X POST "${BASE:-http://127.0.0.1:8000}/rpc" \
  -H "Content-Type: application/json" \
  -H "Authorization: ${AUTH:-tello-api-secret-change-me}" \
  -d '{"jsonrpc":"2.0","method":"connect","params":{},"id":2}'

curl 예시 — connect (호스트·상태 대기 옵션)

curl -s -X POST "${BASE:-http://127.0.0.1:8000}/rpc" \
  -H "Content-Type: application/json" \
  -H "Authorization: ${AUTH:-tello-api-secret-change-me}" \
  -d '{"jsonrpc":"2.0","method":"connect","params":{"host":"192.168.10.1","wait_for_state":true},"id":3}'

GET /snapshot.jpg

단일 JPEG 프레임. 드론 연결 및 stream_on 후에만 의미 있다. 없으면 503과 본문 no frame 가능.

필수 헤더: Authorization

curl 예시 (파일로 저장)

curl -s -H "Authorization: ${AUTH:-tello-api-secret-change-me}" \
  "${BASE:-http://127.0.0.1:8000}/snapshot.jpg" \
  -o /tmp/tello_snapshot.jpg

curl 예시 (HTTP 코드만 확인)

curl -s -o /dev/null -w "%{http_code}\n" \
  -H "Authorization: ${AUTH:-tello-api-secret-change-me}" \
  "${BASE:-http://127.0.0.1:8000}/snapshot.jpg"

GET /stream.mjpeg

multipart/x-mixed-replace MJPEG 스트림. Authorization 필요. 스트림이 켜져 있어야 프레임이 나온다.

curl 예시 (원시 스트림을 파일로, 중단은 Ctrl+C)

curl -N -H "Authorization: ${AUTH:-tello-api-secret-change-me}" \
  "${BASE:-http://127.0.0.1:8000}/stream.mjpeg" \
  -o /tmp/tello_stream.mjpeg

curl 예시 (2초만 받아 앞부분 확인, Ctrl+C로도 중단 가능)

curl -s -N --max-time 2 \
  -H "Authorization: ${AUTH:-tello-api-secret-change-me}" \
  "${BASE:-http://127.0.0.1:8000}/stream.mjpeg" | head -c 512 | xxd | head

JSON-RPC 오류 코드 (참고)

code 의미
-32600 잘못된 요청
-32601 알 수 없는 method
-32602 params 오류
-32603 내부 오류
-32000 드론/연결 등 (not_connected, Tello 응답 등)
